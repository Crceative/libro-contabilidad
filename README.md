# 📘 Libro de Contabilidad

Aplicación PWA para gestionar gastos e ingresos de forma segura y offline.

## ✨ Características

- ✅ **Funciona Offline** - Accede sin internet
- 🔐 **Encripción AES-256** - Tus datos protegidos
- 📊 **Dashboard Completo** - Gráficos y análisis
- 💱 **6 Monedas** - COP, USD, EUR, MXN, ARS, BRL
- 📱 **PWA Instalable** - Como app nativa
- 💾 **IndexedDB** - 500MB de almacenamiento

## 🚀 Instalación

1. Abre el link: https://juanpis117-dev.github.io/libro-contabilidad/)
2. En móvil: Menu → Instalar
3. En PC: Menu → Crear acceso directo

## 🔒 Seguridad

- Datos encriptados localmente
- HTTPS automático en GitHub Pages
- Sin servidores, privacidad total
- Contraseña personal protege todo

## 📝 Uso

1. **Dashboard** - Ve tu resumen financiero
2. **Mis Gastos** - Registra ingresos/gastos
3. **Presupuesto** - Controla por categoría
4. **Reportes** - Exporta a CSV/TXT
5. **Cash Flow** - Proyecciones 2025-2030
